# Plan: `html-channel`, a library for interactive HTML review pages for LLM output

Status: specced 2026-10-16 (frame → research → spike → design → spec) · New repo: `github.com/roterski/html-channel` · Consumer: https://github.com/roterski/ai-behaviors

This file is self-contained. It records why the work is being done, the design decisions
already made, a working prototype, and the steps to build the library. You don't need the
conversation that produced it.

---

## 1. Goal

Stop using `.md` files as the presentation layer when a human reviews LLM-generated code.
The LLM writes **HTML pages** instead. Those pages are **interactive**: buttons record
decisions, and inputs collect notes. The answers come back to the agent.

The result is **one standalone library repo**, consumed in three ways:

| Consumer | Who triggers it | Where |
|---|---|---|
| **Skill** | The agent decides on its own that it needs your input | Claude Code, Claude desktop app; claude.ai (uploaded skill) later |
| **MCP server** (`html-channel mcp`) | The agent calls `ask_human`, which blocks until you click Done | Claude Code, Claude desktop app (ECA if it works at no extra cost) |
| **ai-behaviors tag `#html`** | You, explicitly, per prompt | Claude Code, ECA, via the ai-behaviors hook |

Constraints:
- Local use is localhost only, for a single user. There is no auth, and the server binds to `127.0.0.1` only.
- Page scripting is in **squint** (https://github.com/squint-cljs/squint). Server and CLI are in **babashka**.
- Pages contain **no page-specific JavaScript**. The LLM writes only HTML with `data-*` markers.
  One generic runtime handles everything.
- Pages are served over http only. `file://` is not supported.
- claude.ai is out of scope for v1, and so is ECA-specific work.
- It's a general output channel, not only for code review. Pages live in `<project>/ai/html-channel/`.

## 2. Decisions already made

These were settled on 2026-10-16 through frame → research → spike → design → spec.
Rows marked *(user)* were your call; the rest follow from the research (§2a) or the spike.

| Question | Decision | Why |
|---|---|---|
| Where does the code live? | In its own repo. ai-behaviors only *uses* it. | The library serves three consumers, and ai-behaviors is one of them. |
| Scope of the channel | A general output channel for agents, not a review-specific tool. Files go in `<project>/ai/html-channel/`. *(user)* | Pages can report or ask for decisions about anything. |
| Single source of truth | `CONVENTION.md` in the lib. The skill, the MCP `channel_setup` tool and the `#html` tag point to it. The skill's bundled copy is **generated by `bb build`**. | The consumers can't drift apart. |
| Convention vs transport | The squint runtime has one core and **pluggable transports**. v1 ships `http` only. | claude.ai can't reach localhost. |
| claude.ai support | **Deferred past v1.** *(user)* The core/http split is the hook a later artifact transport plugs into. | Local stdio MCP is impossible there, and remote MCP breaks "localhost, no auth". |
| `file://` pages | **Not supported.** *(user)* Pages are served by the server, and kit references are root-relative (`/_kit/…`). | Dropping `file://` lets the runtime learn its mount from the URL. |
| Threat model | Hostile pages in the same browser are out of scope. *(user)* CORS stays `ACAO: *`. | Localhost, single user. |
| Server lifetime | Every `html-channel mcp` and `serve` process is a **standby**. It registers its root in a user-level `roots.jsonl`, then binds `127.0.0.1:8787`, retrying every 1 s. The port owner serves every registered root. The server dies with its last client. *(user: "let it die", seamless)* | The spike (`ai/spike/takeover-registry.finding.md`) measured takeover at 515–606 ms in 4/4 runs. The port bind is the lock. |
| Multi-project | One port with mounts `/<project-dir-name>-<sha1(abs root)[0..6]>/`. | Keeps one well-known port. |
| Page identity | URL `/<mount>/<session>/<page>.html` maps to `<root>/<session>/<page>.html`, where `<root>` defaults to `<project>/ai/html-channel`. The page id is the file name, and **`data-page` is dropped**. *(user)* | Several agent sessions, each with several pages. |
| Session id | The `session` argument; else the first 8 characters of `CLAUDE_CODE_SESSION_ID`; else a minted 8-hex id. The MCP process remembers it as its default. *(user: 8 chars)* Collisions are accepted and not detected. | After `/clear` the MCP process keeps its spawn-time id. ECA's MCP process has no chat id. |
| Storage | `<root>/<session>/decisions.jsonl`, append-only. Entry: `{page, session, rev, id, value, at}`, where `value: null` means cleared. **No `.gitignore` is written.** *(user)* | Sessions are tracked in git, snapshots included: the decisions are a record. Per-session files never merge-conflict. |
| Revisions | The agent rewrites the same file to revise a page. When the content hash differs from the latest snapshot, the store snapshots it to `<page>@<n>.html`. This check runs at every entry point. Entries carry `rev`, and `done` counts only for the current rev. An open tab reloads on a new rev. *(user)* | Decision history is traceable per version, the URL stays stable, and the agent does nothing extra. |
| Carry-over | Answers carry over to the new rev, marked `data-state="carried"`; `status` doesn't. The runtime adds a "Clear carried answers" button, which records `null` for each carried id. Tools return the effective answers, each with its source `rev`. *(user)* | You only change what's different. |
| Offline detection | The banner is visible by default. The runtime polls `/<m>/<s>/_rev?page=` every 3 s, and a failed poll shows the banner again. | One request covers both health and the rev check. |
| Decisions made while the server is down | Queued in memory, marked `data-state="pending"`, and flushed on reconnect. They are also flushed before any reload. | No lost clicks. |
| Page kinds | **Decision pages** have a final `status=done` button and use `ask_human`. **Report-only pages** have neither. *(user)* | A report has nothing to wait for. |
| How `ask_human` waits | It polls the store until `effective.done`. It sends progress every 30 s and returns `waiting` after `--max-wait` (default 1500 s). Documented fallback: you say "done" in chat and the agent calls `get_decisions`. *(user)* | Claude Code stdio allows 30 min idle and ~28 h wall clock. Desktop is ~60 s. |
| Client support | Claude Code is the primary client. Desktop works via `--max-wait 50`. **ECA is not a goal**, and there is no client detection. *(user)* | Keeps it simple. |
| Names | `channel_setup` (was `review_setup`), `ask_human`, `get_decisions`. The index page is titled "Pages". *(user)* | Not review-specific. |
| Distribution | `bbin install io.github.roterski/html-channel`. It needs `deps.edn` with `:paths ["src" "resources"]`. Static runtime files are classpath resources. | Without `deps.edn`, a git install fails (§2a). |
| squint core dependency | `bb build` rewrites the `'squint-cljs/core.js'` import to `./squint-core.js` and copies the core file next to it. | No CDN or import map. |
| ai-behaviors integration | `behaviors/html/prompt.md` is 2–4 lines deferring to the lib. `./install` runs `bbin install`. | The tag is just text. |

## 2a. Research findings (2026-10-16)

**Session ids** (confirmed: docs and `ps eww` on live processes):

| Where | Id |
|---|---|
| Claude Code Bash and hooks | `CLAUDE_CODE_SESSION_ID`, the same as the hook's `session_id`. Updated on `/clear`. |
| Claude Code MCP process | `CLAUDE_CODE_SESSION_ID` **as it was at spawn**, plus `CLAUDE_PROJECT_DIR`. |
| ECA shell / hooks | `ECA_CHAT_ID` / `chat_id` |
| ECA MCP process | None. Probably one process per server, shared across chats. |

**MCP tool-call timeouts:**

| Client | Limit | Source |
|---|---|---|
| Claude Code (stdio) | 30 min idle, reset by progress notifications (`CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT`). About 28 h wall clock, or the per-server `timeout`. | docs (confirmed) |
| ECA | 120 s, hardcoded. Calls are serialized per server. | `eca/features/tools/mcp.clj:978,1039` (confirmed) |
| Claude desktop | About 60 s. Whether progress notifications extend it is unknown. | issue reports (uncertain) |

**Install and plugin** (confirmed):
- A bbin git install needs a `deps.edn` with `:paths`; `:bbin/bin` is read from `bb.edn`. Verified with a spike, using `io/resource` from a gitlib in an unrelated cwd.
- The Claude Code plugin layout:
  - `skills/<name>/SKILL.md` and `.mcp.json`;
  - `${CLAUDE_PLUGIN_ROOT}` is available in `.mcp.json`;
  - claude.ai and Cowork refuse to install a plugin that has a `bin/`.

**Rejected mechanisms:**
- **Claude Code channels** (`notifications/claude/channel`): a research preview. Custom channels need `--dangerously-load-development-channels` on every launch.
- **Plugin monitors:** interactive sessions only.
- **A URL-scheme "start server" click:** needs an OS app bundle per platform.

**ai-behaviors conventions** (confirmed, repo):
- A behavior is a folder with `prompt.md` and `README.md`.
- `install` and `eca-install` symlink a hook and register it with `jq`.
- `parity_test.clj` requires identical injection from the Claude Code hook, the ECA hook and `core.clj`.
- There is no mechanism for making modifiers exclusive.

## 3. Reference implementation: prototype (verified working)

This is the **single-file prototype** that the library starts from. It is the http transport, the server and the runtime,
before the restructuring described in §5. It was built and tested end to end with Playwright and Chromium, using babashka v1.13.226 and squint-cljs 0.15.212.
Scenarios that passed:
- A: page opened via `file://` with the server down → banner visible.
- C: page opened via `file://` with the server up → banner hidden, and a click is saved (CORS works).
- B: page served over http → previous decisions restored on load. Button, checkbox and textarea values are all saved, and `data-state` becomes `saved`.
- D: server killed mid-session → banner reappears within about 3 s. A click while down shows `pending`. After a restart, the banner hides, the queued decision is flushed, and its state becomes `saved`.
- Path traversal (`/../serve.clj` and `/%2e%2e/serve.clj`) returns 404. A second `bb serve.clj` prints "already running" and exits 0.

Recreate these files verbatim in the new repo as the first commit (phase 0), then restructure.

### 3.1 `serve.clj`

```clojure
#!/usr/bin/env bb
;; Tiny local decision server for interactive review pages.
;;
;;   bb serve.clj                       ; serve ./ on 127.0.0.1:8787
;;   bb serve.clj --root docs/reviews   ; serve another folder
;;   bb serve.clj --port 9000 --out my-decisions.jsonl
;;
;; Idempotent: if a decision server is already answering on the port, it
;; says so and exits 0, so an agent can run it blindly.
;;
;; Endpoints
;;   GET  /_health                 -> {"ok":true,"root":...,"out":...}
;;   GET  /_decisions?page=<id>    -> {"<decision-id>": <latest entry>, ...}
;;   POST /_decisions              -> append one JSON entry to the out file
;;   GET  /_kit/<file>             -> runtime files (decide.mjs, css, squint core)
;;   GET  /                        -> list of .html pages under root
;;   GET  /<path>                  -> static files from root

(ns serve
  (:require [babashka.cli :as cli]
            [babashka.fs :as fs]
            [babashka.http-client :as hc]
            [cheshire.core :as json]
            [clojure.string :as str]
            [org.httpkit.server :as http]))

(def opts
  (cli/parse-opts *command-line-args*
                  {:coerce {:port :long}
                   :alias {:p :port :r :root :o :out}}))

(def port (:port opts 8787))
(def root (fs/canonicalize (:root opts ".")))
(def out-file (fs/path root (:out opts "decisions.jsonl")))
(def kit-dir (fs/canonicalize (fs/path (fs/parent *file*) "kit")))

(def mime
  {"html" "text/html; charset=utf-8" "htm" "text/html; charset=utf-8"
   "js" "text/javascript" "mjs" "text/javascript" "css" "text/css"
   "json" "application/json" "jsonl" "application/x-ndjson"
   "svg" "image/svg+xml" "png" "image/png" "jpg" "image/jpeg"
   "md" "text/markdown; charset=utf-8" "txt" "text/plain; charset=utf-8"})

(def base-headers
  {"Access-Control-Allow-Origin" "*"        ; lets file:// pages talk to us
   "Access-Control-Allow-Methods" "GET, POST, OPTIONS"
   "Access-Control-Allow-Headers" "Content-Type"
   "Access-Control-Allow-Private-Network" "true"
   "Cache-Control" "no-store"})             ; regenerated pages always fresh

(defn respond
  ([status] (respond status nil nil))
  ([status content-type body]
   {:status status
    :headers (cond-> base-headers content-type (assoc "Content-Type" content-type))
    :body body}))

(defn json-resp [data] (respond 200 "application/json" (json/generate-string data)))

(defn query-param [query-string k]
  (some (fn [kv]
          (let [[a b] (str/split kv #"=" 2)]
            (when (= a k) (java.net.URLDecoder/decode (or b "") "UTF-8"))))
        (some-> query-string (str/split #"&"))))

(defn read-entries []
  (when (fs/exists? out-file)
    (keep #(try (json/parse-string % true) (catch Exception _ nil))
          (fs/read-all-lines out-file))))

(defn latest-for-page [page]
  (reduce (fn [m e] (if (= page (:page e)) (assoc m (:id e) e) m))
          {} (read-entries)))

(def write-lock (Object.))

(defn append-entry! [body]
  (let [entry (-> (json/parse-string body true)
                  (update :at #(or % (str (java.time.Instant/now)))))]
    (when-not (and (string? (:page entry)) (string? (:id entry)))
      (throw (ex-info "entry needs string :page and :id" {})))
    (locking write-lock
      (spit (fs/file out-file) (str (json/generate-string entry) "\n") :append true))
    entry))

(defn file-under [dir rel]
  (let [f (fs/canonicalize (fs/path dir rel))]
    (when (and (str/starts-with? (str f) (str dir)) (fs/regular-file? f)) f)))

(defn serve-file [f]
  (respond 200 (get mime (fs/extension f) "application/octet-stream") (fs/file f)))

(defn index-page []
  (let [pages (->> (fs/glob root "**.{html,htm}")
                   (map #(str (fs/relativize root %)))
                   (remove #(str/starts-with? % "node_modules"))
                   sort)]
    (respond 200 "text/html; charset=utf-8"
             (str "<!doctype html><meta charset=utf-8><title>Review pages</title>"
                  "<body style='font:15px system-ui;max-width:40rem;margin:3rem auto'>"
                  "<h1>Review pages</h1><p><code>" root "</code></p><ul>"
                  (apply str (for [p pages] (str "<li><a href='/" p "'>" p "</a>")))
                  "</ul>"))))

(defn handler [{:keys [request-method uri query-string body]}]
  (let [uri (java.net.URLDecoder/decode uri "UTF-8")]
    (try
      (cond
        (= request-method :options) (respond 204)

        (= uri "/_health")
        (json-resp {:ok true :root (str root) :out (str out-file)})

        (and (= uri "/_decisions") (= request-method :get))
        (json-resp (latest-for-page (query-param query-string "page")))

        (and (= uri "/_decisions") (= request-method :post))
        (let [e (append-entry! (slurp body))]
          (println "decision" (:page e) (:id e) "=>" (pr-str (:value e)))
          (json-resp {:ok true}))

        (str/starts-with? uri "/_kit/")
        (if-let [f (file-under kit-dir (subs uri 6))] (serve-file f) (respond 404))

        (= uri "/") (index-page)

        :else
        (if-let [f (file-under root (subs uri 1))] (serve-file f) (respond 404)))
      (catch Exception e
        (respond 400 "text/plain" (ex-message e))))))

(defn already-running? []
  (try (= 200 (:status (hc/get (str "http://127.0.0.1:" port "/_health")
                               {:timeout 500 :throw false})))
       (catch Exception _ false)))

(if (already-running?)
  (println (str "Decision server already running on http://127.0.0.1:" port))
  (do
    (http/run-server handler {:ip "127.0.0.1" :port port})
    (println (str "Serving " root " on http://127.0.0.1:" port))
    (println (str "Decisions -> " out-file))
    @(promise)))
```

### 3.2 `src/decide.cljs` (squint runtime)

```clojure
(ns decide
  "Generic runtime for interactive review pages.

  Conventions in the HTML (no page-specific JS needed):
    <body data-page=\"auth-review\">       page id (defaults to file name)
    <button data-decision=\"x\" data-choice=\"a\">   pick one choice per decision id
    <input|textarea|select data-decision=\"y\">     free-form value, saved on change
    <input type=checkbox data-decision=\"z\">       saved as true/false
    <div id=\"decide-offline\">...</div>            shown while the server is down

  Elements get data-state=\"pending\" until the server confirms, then \"saved\".")

(def server
  (let [u (js/URL. (.-url js/import.meta))] (.-origin u)))

(def page-id
  (or (.. js/document -body -dataset -page)
      (-> js/location .-pathname (.split "/") .pop (.replace #"\.html?$" ""))))

(def state (atom {:online nil :queue [] :flushing false}))

(defn els-for [id]
  (js/document.querySelectorAll (str "[data-decision=\"" (js/CSS.escape id) "\"]")))

(defn mark! [id s]
  (doseq [el (els-for id)] (set! (.. el -dataset -state) s)))

(defn set-online! [online?]
  (when (not= online? (:online @state))
    (swap! state assoc :online online?)
    (when-let [b (js/document.getElementById "decide-offline")]
      (set! (.-hidden b) online?))
    (.toggle (.-classList js/document.documentElement) "decide-is-offline" (not online?))))

(defn ^:async post! [entry]
  ;; no Content-Type header => "simple" CORS request, works from file:// too
  (try
    (let [r (js-await (js/fetch (str server "/_decisions")
                                {:method "POST" :body (js/JSON.stringify entry)}))]
      (.-ok r))
    (catch :default _ false)))

(defn ^:async flush! []
  (when-not (:flushing @state)
    (swap! state assoc :flushing true)
    (loop []
      (when-let [entry (first (:queue @state))]
        (if (js-await (post! entry))
          (do (swap! state update :queue #(vec (rest %)))
              (when-not (some #(= (:id %) (:id entry)) (:queue @state))
                (mark! (:id entry) "saved"))
              (recur))
          (set-online! false))))
    (swap! state assoc :flushing false)))

(defn record! [id value]
  (swap! state update :queue conj
         {:page page-id :id id :value value :at (.toISOString (js/Date.))})
  (mark! id "pending")
  (flush!))

;; ---- reading / writing element values ------------------------------------

(defn el-value [el]
  (if (= "checkbox" (.-type el)) (.-checked el) (.-value el)))

(defn restore! [decisions]
  (doseq [[id entry] (js/Object.entries decisions)]
    (let [v (:value entry)]
      (doseq [el (els-for id)]
        (set! (.. el -dataset -state) "saved")
        (cond
          (= "BUTTON" (.-tagName el))
          (.toggle (.-classList el) "chosen" (= v (.. el -dataset -choice)))

          (= "checkbox" (.-type el)) (set! (.-checked el) (boolean v))
          (= "radio" (.-type el)) (set! (.-checked el) (= v (.-value el)))
          :else (set! (.-value el) v))))))

;; ---- events --------------------------------------------------------------

(.addEventListener js/document "click"
  (fn [e]
    (when-let [btn (.closest (.-target e) "button[data-decision][data-choice]")]
      (let [id (.. btn -dataset -decision)]
        (doseq [b (els-for id)] (.remove (.-classList b) "chosen"))
        (.add (.-classList btn) "chosen")
        (record! id (.. btn -dataset -choice))))))

(.addEventListener js/document "change"
  (fn [e]
    (let [el (.-target e)]
      (when (and (.. el -dataset -decision) (not= "BUTTON" (.-tagName el)))
        (record! (.. el -dataset -decision) (el-value el))))))

;; ---- health polling ------------------------------------------------------

(defn ^:async check! []
  (let [ok (try (.-ok (js-await (js/fetch (str server "/_health") {:cache "no-store"})))
                (catch :default _ false))]
    (set-online! ok)
    (when (and ok (seq (:queue @state))) (flush!))
    ok))

(defn ^:async init! []
  (when (js-await (check!))
    (try
      (let [r (js-await (js/fetch (str server "/_decisions?page=" (js/encodeURIComponent page-id))))]
        (restore! (js-await (.json r))))
      (catch :default e (js/console.warn "decide: could not restore" e))))
  (js/setInterval check! 3000))

(init!)
```

### 3. Store
Files live under `<root>/<session>/`, where `<root>` defaults to `<project>/ai/html-channel`.

- **3.1 [MUST]** Decisions go to `<root>/<session>/decisions.jsonl`, append-only.
  Each entry is `{page, session, rev, id, value, at}`, and `value: null` means cleared.
  Done: two sessions write two separate files, and no line is ever rewritten.
- **3.2 [MUST]** `current-rev(session, page)` hashes `<page>.html` and compares it with the latest `<page>@<n>.html`.
  If they differ, or no snapshot exists, it copies the page to `<page>@<n+1>.html` and returns n+1. Otherwise it returns n.
  Done:
  - the first call returns 1 and creates `@1`;
  - 100 calls on an unchanged file still return 1;
  - one rewrite gives exactly 2.
- **3.3 [SHOULD]** Two processes snapshotting at once produce one snapshot: an exclusive create, then a hash recheck.
  Done: 2 processes × 50 parallel calls after one rewrite produce exactly one new snapshot.
- **3.4 [MUST]** `effective(session, page)` returns `{rev, done, decisions: {id → {value, rev, at}}}`.
  - It takes the latest entry per id across all revs, except `status`, which is counted only from the current rev.
  - `done` means there is a `status=done` entry for the current rev.

  Done (unit tests):
  - a rev-1 `done` gives `done: false` at rev 2;
  - a rev-1 answer appears with `rev: 1` at rev 2;
  - a `null` entry at rev 2 overrides a rev-1 value.
- **3.5 [MUST]** Every entry point calls `current-rev` before reading or writing: the page GET, `_rev`, `_decisions`, and every MCP tool and CLI command.
  Done: no entry point reads entries without going through it.
- **3.6 [MAY]** Snapshots can be viewed at `/<mount>/<session>/<page>@<n>.html`.

```python
import subprocess, time, json, pathlib
from playwright.sync_api import sync_playwright
# run from the html-channel folder: python3 e2e.py
KIT = pathlib.Path(".").resolve(); OUT = KIT/"examples/decisions.jsonl"
SRV=[]
def start():
    p = subprocess.Popen(["bb","serve.clj","--root","examples"],cwd=KIT,stdout=subprocess.DEVNULL); time.sleep(1.5); SRV.append(p); return p
def stop():
    while SRV: p=SRV.pop(); p.terminate(); p.wait()
    time.sleep(0.5)
stop(); OUT.unlink(missing_ok=True)
with sync_playwright() as pw:
    b = pw.chromium.launch(); pg = b.new_page()
    errs=[]; pg.on("console", lambda m: m.type=="error" and errs.append(m.text))
    # A: server down, file://
    pg.goto(f"file://{KIT}/examples/demo.html"); time.sleep(1)
    print("A file:// + server down  -> banner visible:", pg.is_visible("#decide-offline"))

    srv = start(); pg.reload(); time.sleep(1.5)
    print("C file:// + server up    -> banner visible:", pg.is_visible("#decide-offline"))
    pg.click("button[data-choice=ttl]"); time.sleep(0.5)
    # B: served over http
    pg.goto("http://127.0.0.1:8787/demo.html"); time.sleep(1)

    pg.fill("[data-decision=notes]","rename evict! to evict"); pg.click("h1"); time.sleep(0.7)
    print("   state after save      ->", pg.get_attribute("[data-decision=notes]","data-state"))
    # D: server dies mid-session
```

## 8. Gotchas already hit

- `squint compile src/decide.cljs --output-dir build` writes to `build/src/decide.mjs`, not `build/decide.mjs`.
- Module scripts need a correct `Content-Type: text/javascript`, which is why the server has a MIME map. Browsers enforce strict MIME checking for modules.
- `import.meta.url` works in squint as `(.-url js/import.meta)`. The runtime derives the server origin from it, so the port lives only in the page's `<script src>`.
- `js-await` inside `loop`/`recur` is fine in squint, because the loop compiles to a JS `while` inside the async function.
- In tests, don't kill the server with `pkill -f '<pattern>'` run from a shell whose own command line contains the pattern. It kills the shell itself. Keep the `Popen` handle and call `terminate()`.
- MCP over stdio: **anything printed to stdout that isn't JSON-RPC breaks the client**. The prototype `println`s request logs to stdout, so move all logging to stderr (`binding [*out* *err*]`) before adding `mcp`.
- With bbin installing from git, the code runs from a gitlib checkout. Paths relative to `*file*` happen to still work there, but classpath resources are the robust choice, and they're what step 3 uses.

- A bbin git install fails with "Manifest file not found" when there is no `deps.edn`. `bb.edn` alone is not enough.
- `CLAUDE_CODE_SESSION_ID` in an MCP process is the spawn-time id. Bash sees a new id after `/clear`.
- ECA hardcodes a 120 s MCP tool-call timeout and runs calls one at a time per server.
- `(def [a b] …)` isn't destructuring. It throws `ClassCastException` (hit in the spike).
