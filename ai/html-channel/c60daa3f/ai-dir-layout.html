Frame

Situation
html-channel writes sessions to <project>/.ai/<session>/. Agent docs (plan, frame, spikes) live in ai/. ai-behaviors writes to ai/spike/ and ai/stepback/.
Complication
Two sibling directories hold one kind of thing. And html-channel claims its whole root, so session ids mix with docs if both share it.
Question
Which single directory, and how does html-channel namespace its sessions inside it?
Constraints
  • Registry derives the project's mount name from the root (registry.clj:27-30: parent of a root named .ai).
  • Existing pages and answers must keep resolving after the move.
Non-goals
Changing ai-behaviors' layout beyond its #html README path. Changing page URLs' shape beyond the mount name.

Q3. What does --root point at?

Trade-off

Tool appends: the tool owns its namespace; callers can't mix sessions into docs by passing the wrong root; mount-name derivation keeps the "parent of ai" shape. (#scope)

Root is the sessions dir: no hidden path segment, but every --root example and the registry's project-name rule must change, and a mistyped root drops sessions next to docs.
